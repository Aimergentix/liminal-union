# STYLE_GUIDE.md

Binding file for tone, diction, and terminology. If a lower file conflicts with this guide on wording or register, this file wins.

## Core voice

Write the Union as:
- ancient, civic, stiff-necked, and severe;
- measured rather than florid;
- archaic in cadence without parody;
- rational without sounding clinical;
- Wesnothian rather than science-fictional.

The Union should not read like modern ideology in costume, modern bureaucracy, or futuristic interface text.

## Doctrinal phrasing

Prefer:
- **anti-sorcerous**
- **hostile to living spellcraft**
- **opposed to mage-rule**
- **opposed to occult sovereignty**
- **permits arcane matter bound in natural or crafted vessels**

Do not flatten this into simple “anti-magic” language when precision matters.  
Do not imply that the Union rejects all arcane matter.

## Preferred terminology

Use these as the default public vocabulary:

| Concept | Preferred |
|---|---|
| doctrine | anti-sorcerous; Ban on Living Spellcraft |
| craft | lawful artifice; disciplined craft; lawful inquiry |
| materials | arcane matter; Arcanite; Pyrite; Kryonite; Uranite; Zoelite; Akosite; bound core; sealed core; radiant core |
| rites and compacts | Eighth-Day Severance; Catharite bath; smelting-milk; Treaty of the Living and the Bound; Dark Forest Charter |
| polity | commonwealth; public corps; civic law; charter; compact |
| warforms | warform; Quickbound Golem; Corebound Warform |
| records | annals; sealed annals |
| Ruby of Fire in Sayyoni voice | Scarlet Faerie Stone |

## Controlled exceptions

These may remain where technical clarity or established labels require them:
- `G9`
- `NCM`
- `AI`, but only in raw labels or technical notes
- `engineering` or `technology`, but only in README-level or developer-facing prose

## Avoid in lore-facing prose

Do not use these as default lore diction:
- cyborg
- robot
- android
- artificial intelligence
- mechatronics
- software / hardware / interface / protocol / algorithm
- revolutionary
- intersectionalist
- fascist-like
- socialist
- free-market social-state
- leader-principle
- politburo

These terms either break tone or contradict the project’s own style rules.

## Naming rules

Institutional and place names should sound old, formal, and legible:
- Sayyon
- Salem
- High Courts of Evercrown
- Crown-Realms of 
- High Courts of Wesnoth
- Crown-Realms of Wesnoth
- Sun-Scar Necrodominion

Use gameplay labels where necessary, but frame them in older diction when writing lore prose.

## File register

- `CANON_LOCK.md`: exact and spare
- `HISTORY.md`: chronological and annal-like
- `LORE.md`: richest prose in the docs, but still disciplined
- `README.md`: clear and practical
- `GenAI_GUIDE.md`: procedural, not lore-bearing

## Editorial test

Before keeping a sentence, ask:
1. Does it agree with `CANON_LOCK.md`?
2. Does it sound older, civic, and severe?
3. Does it preserve the distinction between arcane matter and living spellcraft?
4. Does it avoid modern ideological or science-fiction framing?

If not, rewrite it.
