# Liminal Union

Liminal Union is a Wesnoth UMC setting and faction centered on **Sayyon / Salem**, an ancient southern commonwealth across the Black River. In canon, the Union is **anti-sorcerous in agency, not anti-arcane in substance**: it rejects living spellcraft, hereditary magical sovereignty, and necromancy, yet permits arcane matter bound within natural and crafted artifice.

This README is an entry point only. It does not define canon, style, diplomacy, or implementation guarantees.
